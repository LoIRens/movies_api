## Каталог фильмов (Movies API)

## Краткое описание проекта

REST API приложение для управления каталогом фильмов, разработанное на FastAPI. 
Позволяет создавать, просматривать, редактировать и удалять информацию о фильмах. 
Реализована асинхронная работа с базой данных SQLite, фильтрация и сортировка списка фильмов.

## Основные возможности приложения

- Создание нового фильма
- Получение списка всех фильмов с пагинацией
- Получение информации о конкретном фильме по ID
- Полное обновление данных фильма (PUT)
- Частичное обновление данных фильма (PATCH)
- Удаление фильма из каталога
- Фильтрация по году выпуска и минимальному рейтингу
- Сортировка по названию, году, рейтингу и ID

## Технологический стек

- Python 3.10+
- FastAPI 0.143.0 — веб-фреймворк
- SQLAlchemy 2.1.4 — ORM для работы с БД
- aiosqlite 0.22.1 — асинхронный драйвер SQLite
- Alembic 1.20.0 — миграции базы данных
- Pydantic 2.14.0 — валидация данных
- Uvicorn 0.54.0 — ASGI сервер
- pytest 9.1.1 — тестирование

##  Быстрый старт

### 1. Клонирование репозитория

git clone https://github.com/LoIRens/movies_api.git

### 2. Установка зависимостей 

pip install -r requirements.txt

### 3. Применение миграйций

alembic upgrade head

### 4. Запуск приложения через unicorn

uvicorn src.main:app --reload
по адресу: http://localhost:8000

## Основные эндпоинты 

Метод GET, эндпоинт (/) - проверка работы API;

Метод GET, эндпоитн (/movies/) - список всех фильмов;

Метод GET, эндпоинт (/movies/{movies_id}) - ID фильма;

Метод POST, эндпоинт (/movies/) - создание нового фильма;

Метод PUT, эндпоинт (/movies/{movie_id}) - обновить фильм полностью;

Метод PATCH, эндпоинт (/movies/{movie_id}) - обновить фильм частично;

Метод DELETE, эндпоинт (/movies/{movie_id}) - удалить фильм

## Фильтрации и сортировка 
limit - количество записей (максимально 100)
offset - смещение
year_min - минимальный год выпуска
year_max - максимальный год выпуска
min_rating - минимальный рейтинг
order_by - сортировка (title, year, rating)

## Модель данных 

id - int - первичный ключ
title - str - название фильма (2-200 символов)
genre - str - жанр (2-100 символов)
rating - float - рейтинг от 0 до 10
year - int - год выпуска (1888 - текущий год)


## Ограничения базы данных

Рейтинг должен быть от 0 до 10

Год выпуска не может быть меньше 1888
