# Каталог фильмов

## Краткое описание проекта
REST API приложение для управления каталогом фильмов. 
Позволяет добавлять, просматривать, редактировать и удалять информацию о фильмах. 
Реализовано на FastAPI с асинхронной базой данных.

## Основные возможности приложения
- Просмотр списка всех фильмов
- Получение информации о конкретном фильме по ID
- Добавление нового фильма в каталог
- Редактирование данных о фильме
- Удаление фильма из каталога
- Фильтрация фильмов по жанру и году
- Сортировка списка фильмов

## Технологический стек
- **Python 3.10+**
- **FastAPI** — веб-фреймворк
- **SQLAlchemy 2.0** — ORM для работы с БД
- **Alembic** — миграции базы данных
- **aiosqlite** — асинхронная SQLite база данных
- **Pydantic** — валидация данных
- **Uvicorn** — ASGI сервер
- **pytest** — тестирование
